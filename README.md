## 📋 About

This is a fully responsive portfolio that features:

- **Profile Section**: A code editor-style hero section with interactive tabs showing profile info and photo
- **Technical Skills**: Terminal-styled skills display organized by category (Languages, Frontend, Backend, Database, Tools)
- **Career Timeline**: A clean timeline showcasing education and professional experience
- **Projects Portfolio**: Showcase of 3 full-stack and ML projects with descriptions and GitHub links
  - Opticverse 3D (AR/VR Simulation)
  - Online Medical Appointment Website (MERN Stack)
  - Alzheimer's Detection using Machine Learning
- **Certifications**: Grid display of earned certifications
- **Achievements**: Statistics and key accomplishments
- **Contact Section**: Multiple ways to connect (email, phone, GitHub)

## 🎨 Features

- **Dark Theme**: Professional dark color scheme with accent colors
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Interactive Navigation**: Smooth scrolling with sidebar/topbar navigation
- **Modern UI**: Code editor aesthetic with terminal-styled sections
- **Zero Dependencies**: Pure HTML, CSS, and vanilla JavaScript - no frameworks required

## 🛠️ Tech Stack

- HTML5
- CSS3 (with CSS Grid & Flexbox)
- Vanilla JavaScript (ES6+)
- Google Fonts (Space Grotesk, Inter, JetBrains Mono)
